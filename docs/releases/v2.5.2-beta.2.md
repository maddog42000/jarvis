# v2.5.2-beta.2

This beta adds the following user-facing improvements:

- The chat activity indicator now shows whether JARVIS is thinking or working, with elapsed time. It does not expose hidden model reasoning or invent a completion percentage.
- Appearance settings include additional coordinated accent-color palettes and an optional local centerpiece image. PNG, JPEG, and WebP files are resized before storage; remote image URLs are not accepted, and the existing orb/reactor remains the fallback.
- Chat now has Play/Pause/Resume and approximate −5s/+5s speech controls. Because live Android text-to-speech does not provide a seekable audio timeline, skips restart from an estimated nearby point in the reply rather than a precise audio timestamp.

This is a beta prerelease. Android update installation requires the same signing key as the installed app; if the signing key is rotated, uninstall the prior build before installing this one (after backing up any local data).
